Writes the build into the selected disk's saved state; the image file is untouched. Builds from 1998 on need a matching boot ROM (above). The LPT patch makes the build go online through the parallel-port bridge instead of its modem. It uses the build's symbols.sym when there is one (pick it together with a local _approm.o); otherwise it finds what it needs in the code by signature.
